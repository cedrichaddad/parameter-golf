# Design System

Canvas: 1280 x 720.

Style: white/off-white engineering deck, dark text, one validated blue, one diagnostic amber, one failure red, one measured green. Charts and tables use native editable shapes.

Palette:
- Background: #F7F3EA
- Ink: #17212B
- Muted: #5B6573
- Rule: #D7D0C3
- Accent blue: #2D6CDF
- Measured green: #0A8F64
- Diagnostic amber: #D9822B
- Not implemented red: #C2413D
- Soft panel: #FFFFFF

Badges:
- MEASURED: green
- DIAGNOSTIC: amber
- NOT IMPLEMENTED: red
- RECORD-CLEAN: blue

Typography:
- Aptos Display for titles
- Aptos for body
- Aptos Mono for metric labels
